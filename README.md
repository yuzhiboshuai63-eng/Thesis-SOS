# Thesis SOS - 论文急救全能助手

SOLO Skill for academic paper rewriting, AI detection reduction, quality review, and style analysis. Supports Chinese and English.

## ✨ 八大核心功能

| 功能 | 描述 |
|------|------|
| **降重复率** | 3级强度（轻度/中度/深度），一键大幅降低重复率 |
| **降AI率** | 5级微度模式 + AI移除模式，精准控制改写幅度 |
| **降重+降AIGC** | 同时优化重复率和AI率，全面提升质量 |
| **AI率预测** | 多平台AI率预估，提前了解检测风险 |
| **论文格式学习与模仿改写** | 学习目标论文风格，按其风格改写 ⭐ |
| **错别字检测与标注** | 中英文错别字、标点、语法全面检测 ⭐ |
| **学术英语核对与优化** | 语法、用词、时态、语态学术规范检查 ⭐ |
| **文献来源检测与标注** | 文献存在性、格式规范、引用一致性审查 ⭐ |

## 🎯 降AI率 - 5级微度模式

从上到下，改写幅度依次增加：

| 模式 | 改写幅度 | 降AI能力 | 学术性 | 适用AI率 |
|------|----------|----------|--------|----------|
| 微度模式1 | 最小 | 基础 | 极高 | 10-20% |
| 微度模式2 | 较小 | 轻度 | 极高 | 20-35% |
| 微度模式3 | 中等 | 中等 | 高 | 35-50% |
| 微度模式4 | 较大 | 较强 | 中高 | 50-70% |
| 微度模式5 | 最大 | 强 | 中 | >70% |
| **AI移除** | 小 | 一般 | **极高** | <30% |

## 🆕 新增功能详解

### 论文格式学习与模仿改写

```
输入：目标论文（范文/导师论文/目标期刊论文）+ 用户论文
输出：写作风格画像 + 模仿改写后文本 + 风格对比报告

学习维度：句式风格、用词习惯、段落结构、论证方式、表达特色、标题风格
```

### 错别字检测与标注

```
中文：同音字误用、形近字混淆、多字/少字、语法错误、量词错误
英文：拼写错误、语法错误、冠词错误、搭配错误
标点：中英文标点规范检测
输出：带位置标注的错误列表 + 修正建议 + 修正后文本
```

### 学术英语核对与优化

```
语法检查：主谓一致、时态一致性、冠词、介词搭配、代词指代、平行结构
学术用词：非学术→学术表达替换（10组常见替换）
时态语态：各论文章节推荐时态 + 被动语态使用规范
输出：语法错误列表 + 用词替换列表 + 优化后文本
```

### 文献来源检测与标注

```
存在性检测：网络搜索验证文献真实性 + DOI有效性
格式规范：GB/T 7714 / APA / MLA / IEEE / Chicago
引用一致性：正文引用 vs 参考文献列表匹配
输出：文献可信度评估 + 格式问题列表 + 引用一致性报告
```

## 🎓 毕业生专用功能

### 一键降重套餐

| 套餐 | 适用场景 |
|------|----------|
| 本科毕业论文套餐 | 降重复率-深度 + 降AI-微度模式3 + 全面校对 |
| 硕士毕业论文套餐 | 降重复率-深度 + 降AI-微度模式4 + 学术英语核对 |
| 博士毕业论文套餐 | 降重复率-深度 + AI移除模式 + 全面文献审查 |
| SCI投稿套餐 | 降重复率-中度 + 全面英语优化 + 文献格式规范(APA) |
| 核心期刊套餐 | 降AI-微度模式2 + 格式模仿改写 + 引用一致性 |
| 紧急降重套餐 | 降重复率-深度 + 降AI-微度模式5 |
| **论文终审套餐** | 全面校对 + 全面英语优化 + 全面文献审查 |
| **导师风格套餐** | 格式学习 + 模仿改写 + 降AI-微度模式2 |

### 其他功能

- **智能分段处理** - 自动根据章节选择最佳模式
- **多平台适配** - 一键生成适配不同平台的版本
- **引用保护模式** - 智能识别并保护引用内容
- **格式保持** - 保持原文档格式（docx输出）
- **对比视图** - 原文与改写文本逐句对照
