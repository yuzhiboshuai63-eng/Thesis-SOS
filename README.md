# Paper Reduce - 中文学术论文智能降重工具

SOLO Skill for Chinese academic paper rewriting and AI detection reduction.

## 功能特性

本 Skill 提供四种核心模式，帮助用户有效降低论文重复率和 AI 生成痕迹：

| 模式 | 功能描述 |
|------|----------|
| **降重复率（深度）** | 全网领先的降重技术，一键大幅降低重复率，保证学术表达 |
| **降AI率** | 优化文本内容，降低AI生成痕迹，使文章更具人文特色 |
| **降重+降AIGC** | 同时降低重复率和AI生成痕迹，全面提升文章质量 |
| **AI率预测** | 选择对应算法，比对应平台更严格地预测AI率 |

## 安装

将 `paper-reduce` 文件夹复制到 SOLO 的 skills 目录：

```bash
cp -r paper-reduce /data/user/skills/
```

## 使用方法

- "降低重复率"

- "降AIGC"

## 核心工作流

1. **Phase 0**: 模式选择与配置（选择降重模式、检测平台、输入方式）
2. **Phase 1**: 文本输入与预处理（识别结构、标记不可修改区域）
3. **Phase 2**: 智能降重处理（根据模式执行对应改写策略）
4. **Phase 3**: 质量检查与校验（语义完整性、学术规范性、降重效果）
5. **Phase 4**: 结果输出（改写后文本、效果摘要、修改标注）

## 改写策略

### 降重复率策略

1. **语义深度改写** - 重新理解原文含义并用不同方式表达
2. **句式结构变换** - 主动/被动、长句/短句、正装/倒装
3. **同义词替换** - 高频学术词汇的多样化表达
4. **段落逻辑重组** - 调整论证顺序、合并/拆分
5. **知网专项优化** - 针对13字符连续匹配的特别处理

### 降AI率策略

1. **打破AI句式模式** - 制造句长波动、减少机械过渡词
2. **增加个人写作风格** - 加入作者视角的判断和评价
3. **增加文本"不完美性"** - 增加具体案例和细节
4. **降低AI检测特征值** - 优化困惑度和突发性

## 注意事项

- 仅支持中文论文
- 专有名词、数据、公式、引用内容不会被修改
- 建议每次处理 3000-5000 字
- 改写后请人工审核学术准确性
