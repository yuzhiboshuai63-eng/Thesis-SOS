# Paper Reduce - 学术论文智能降重与AI检测优化工具

SOLO Skill for academic paper rewriting and AI detection reduction. Supports Chinese and English.

## ✨ 功能特性

### 四大核心功能

| 功能 | 描述 |
|------|------|
| **降重复率** | 3级强度（轻度/中度/深度），一键大幅降低重复率 |
| **降AI率** | 5级微度模式 + AI移除模式，精准控制改写幅度 |
| **降重+降AIGC** | 同时优化重复率和AI率，全面提升质量 |
| **AI率预测** | 多平台AI率预估，提前了解检测风险 |

### 支持语言

- 🇨🇳 **中文** - 知网、维普、格子达等中文平台
- 🇬🇧 **英文** - PaperPass、PaperYY等国际平台

## 🎯 降AI率 - 5级微度模式

从上到下，改写幅度依次增加：

| 模式 | 改写幅度 | 降AI能力 | 学术性 | 适用场景 |
|------|----------|----------|--------|----------|
| 微度模式1 | 最小 | 基础 | 极高 | AI率10-20% |
| 微度模式2 | 较小 | 轻度 | 极高 | AI率20-35% |
| 微度模式3 | 中等 | 中等 | 高 | AI率35-50% |
| 微度模式4 | 较大 | 较强 | 中高 | AI率50-70% |
| 微度模式5 | 最大 | 强 | 中 | AI率>70% |
| **AI移除** | 小 | 一般 | **极高** | 学术性优先 |

**AI移除模式特点**：降AI能力一般，改写幅度小，学术性强，非一逗到底

## 🎓 毕业生专用功能

### 一键降重套餐

| 套餐 | 适用场景 |
|------|----------|
| 本科毕业论文套餐 | 降重复率-深度 + 降AI-微度模式3 |
| 硕士毕业论文套餐 | 降重复率-深度 + 降AI-微度模式4 |
| 博士毕业论文套餐 | 降重复率-深度 + AI移除模式 |
| 期刊投稿套餐 | 降AI-微度模式2 + 对比视图 |
| 紧急降重套餐 | 降重复率-深度 + 降AI-微度模式5 |

### 其他功能

- **智能分段处理** - 自动根据章节选择最佳模式
- **多平台适配** - 一键生成适配不同平台的版本
- **引用保护模式** - 智能识别并保护引用内容
- **格式保持** - 保持原文档格式（docx输出）
- **对比视图** - 原文与改写文本逐句对照

## 📦 安装

将 `paper-reduce` 文件夹复制到 SOLO 的 skills 目录：

```bash
cp -r paper-reduce /data/user/skills/
```

## 🚀 使用方法

在 SOLO 中提及以下关键词即可触发本 Skill：

- "论文降重"、"降低重复率"、"降AI率"
- "论文改写"、"降AIGC"、"AI率预测"
- "格子达降重"、"知网降重"、"中英文降重"

### 使用流程

1. **选择语言** - 中文或英文
2. **选择检测平台** - 知网/维普/格子达等
3. **选择处理模式** - 根据需求选择对应模式
4. **输入文本** - 粘贴文本或上传文件
5. **获取结果** - 改写后文本 + 对比视图 + 效果摘要

## 📝 使用示例

```

```

## ⚠️ 注意事项

### 使用限制

- 单次处理最多100000字符
- 中文和英文分别处理，不要混用
- PDF输入可能丢失格式，建议转换为docx

### 学术诚信

- 本工具仅用于辅助改写，**不能替代原创研究**
- 改写后请**人工审核**学术准确性
- 确保改写内容**符合学术规范**
- **不得用于学术不端行为**

### 效果说明

- 降重效果因原文质量、学科领域、检测平台而异
- 预估效果仅供参考，**实际结果以检测系统为准**
- 建议改写后使用目标平台官方检测验证
