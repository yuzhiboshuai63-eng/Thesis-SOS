# 各检测平台算法特点与针对性改写策略

本文档详细分析各主流检测平台的算法特点，并提供针对性的改写策略。

---

## 一、知网（CNKI）

### 1.1 检测算法特点

| 维度 | 详细说明 |
|------|----------|
| **核心算法** | 基于13个连续字符匹配规则 |
| **匹配规则** | 如果与数据库中的文献有连续13个字符相同，即标记为重复 |
| **语义检测** | 较新版本已加入语义级别检测，同义词替换可能被识别 |
| **AIGC检测** | 2024年起已集成AI生成检测功能 |
| **数据库** | 拥有最全面的中文学术文献数据库 |
| **检测范围** | 期刊论文、学位论文、会议论文、报纸、网络资源等 |
| **灵敏度** | 高，是目前最严格的中文查重系统 |

### 1.2 针对性改写策略

```
核心原则：确保任意连续13个中文字符不与原文相同

策略1：深度语义改写（最有效）
  - 不能仅替换同义词，必须改变表达方式
  - 用完全不同的句式重新阐述
  - 示例：
    原文："随着人工智能技术的不断发展，深度学习在图像识别领域取得了显著的成果"
    改写："近年来，得益于计算能力的提升和海量数据的积累，基于神经网络的视觉感知系统在多项基准测试中表现优异"

策略2：打断连续字符
  - 在关键位置插入修饰语
  - 改变数字和单位的表述方式
  - 示例：
    原文："实验结果表明准确率达到了95.3%"
    改写："从测试结果来看，模型的识别精度约为95.3%"

策略3：改变句式结构
  - 主动句改被动句
  - 长句拆分为短句
  - 改变主语和语序
  - 示例：
    原文："本文提出了一种基于Transformer的文本分类方法"
    改写："针对文本分类任务，一项以自注意力机制为核心的全新方案被设计并实现"

策略4：知网AIGC专项
  - 增加句式多样性
  - 避免AI高频词汇
  - 加入个人化表达
```

### 1.3 知网降重注意事项

- ❌ 不要仅做同义词替换（知网新版可识别语义相似）
- ❌ 不要仅调整语序（13字符匹配仍会触发）
- ✅ 必须进行深度语义改写
- ✅ 数字和专有名词之间的连接词也需变化
- ✅ 注意参考文献格式的细微差异

## 二、维普（VIP）

### 2.1 检测算法特点

| 维度 | 详细说明 |
|------|----------|
| **核心算法** | 关键词匹配 + 句子结构分析双重检测 |
| **匹配规则** | 不仅检测连续字符，还分析句子结构和关键词分布 |
| **段首权重** | 段落首句的权重较高 |
| **语义检测** | 有一定语义理解能力 |
| **数据库** | 期刊论文、学位论文、报纸等 |
| **灵敏度** | 中高，对句式变化较敏感 |

### 2.2 针对性改写策略

```
核心原则：同时改变关键词和句子结构

策略1：关键词替换 + 句式变换（双管齐下）
  - 示例：
    原文："采用深度学习算法对文本数据进行情感分析"
    改写："借助神经网络模型，对大量评论文本的情绪倾向进行了系统性研判"

策略2：段落首句重点改写
  - 维普对段首权重高，首句必须彻底改写
  - 示例：
    原文首句："深度学习是人工智能领域的重要分支"
    改写首句："作为机器学习的一个子领域，深度神经网络在近十年间经历了爆发式增长"

策略3：改变句子结构
  - 合并或拆分句子
  - 改变主语和宾语的位置
  - 使用不同的语法结构
```

## 三、万方（Wanfang）

### 3.1 检测算法特点

| 维度 | 详细说明 |
|------|----------|
| **核心算法** | 段落级模糊匹配 |
| **匹配规则** | 以段落为单位进行相似度计算，允许一定程度的差异 |
| **模糊度** | 较高，不要求完全相同的字符 |
| **数据库** | 期刊论文、学位论文、会议论文等 |
| **灵敏度** | 中等，对段落整体结构变化敏感 |

### 3.2 针对性改写策略

```
核心原则：重组段落结构和逻辑顺序

策略1：段落内部逻辑重组
  - 改变论证顺序（因果→递进、总分→分总）
  - 示例：
    原文："因为A，所以B。此外，C也是原因之一。"
    改写："B的出现可以追溯到两个源头：其一是A的影响，其二则是C的作用。"

策略2：段落拆分与合并
  - 将长段落拆分为多个短段落
  - 将相关短段落合并为一个长段落
  - 改变段落长度分布

策略3：论述角度调整
  - 从不同视角阐述同一观点
  - 示例：
    原文："该方法提高了系统的性能"
    改写："系统在引入该方案后，其整体运行表现得到了可观的改善"
```

## 四、PaperPass

### 4.1 检测算法特点

| 维度 | 详细说明 |
|------|----------|
| **核心算法** | 严格连续字符匹配 |
| **匹配规则** | 对连续相同字符非常敏感，比知网更严格 |
| **数据库** | 互联网资源 + 学术文献 |
| **灵敏度** | 高，对连续字符匹配非常严格 |

### 4.2 针对性改写策略

```
核心原则：打断所有连续相同字符

策略1：全面改写
  - 不能保留任何连续相同的长短语
  - 示例：
    原文："基于深度学习的图像识别技术在医疗领域具有广阔的应用前景"
    改写："将神经网络方法引入医学影像分析，这一方向正展现出极大的发展潜力"

策略2：增加或减少修饰语
  - 在关键位置插入或删除修饰语
  - 示例：
    原文："实验结果表明该方法有效"
    改写："多轮对照实验的数据充分证实了所提方案的可行性和有效性"

策略3：完全改变表达方式
  - 用完全不同的词汇和句式重新表达
```

## 五、格子达（Gezida）

### 5.1 检测算法特点

| 维度 | 详细说明 |
|------|----------|
| **核心算法** | AI生成检测 + 重复率检测 |
| **AIGC检测** | AI检测较为严格，对AI特征敏感 |
| **重复率检测** | 基于连续字符匹配 |
| **灵敏度** | AI检测方面较高 |

### 5.2 针对性改写策略

```
核心原则：重点消除AI特征

策略1：降低AI检测率
  - 增加句式多样性
  - 打破AI句式模式
  - 加入个人化表达
  - 参考ai_patterns.md中的具体技巧

策略2：同时降低重复率
  - 执行标准的降重策略
  - 确保改写后的文本不具有AI特征
```

## 六、PaperYY

### 6.1 检测算法特点

| 维度 | 详细说明 |
|------|----------|
| **核心算法** | 综合检测（重复率 + AI检测） |
| **特点** | 检测维度多，覆盖面广 |
| **灵敏度** | 中高 |

### 6.2 针对性改写策略

```
核心原则：多维度改写

策略1：综合运用所有改写策略
  - 语义改写 + 句式变换 + 同义词替换
  - 同时关注重复率和AI特征

策略2：全面质量检查
  - 改写后进行全面的质量检查
  - 确保在多个维度上都通过检测
```

## 七、其他平台

### 7.1 笔杆网

| 特点 | 策略 |
|------|------|
| 偏重句子级匹配 | 重点改写句子结构 |
| 对专有名词敏感 | 专有名词之间的连接词需变化 |

### 7.2 华宸

| 特点 | 策略 |
|------|------|
| 中等严格度 | 标准改写策略即可 |
| 对段落结构敏感 | 注意段落重组 |

### 7.3 paperred / writepass / papered

| 特点 | 策略 |
|------|------|
| 综合检测 | 多维度改写 |
| AI检测能力参差不齐 | 根据具体平台调整 |

### 7.4 大雅

| 特点 | 策略 |
|------|------|
| 互联网资源匹配强 | 注意网络资源的引用 |
| 对网络用语敏感 | 避免使用网络流行语 |

### 7.5 朱雀

| 特点 | 策略 |
|------|------|
| 新兴平台 | 标准改写策略 |
| 算法持续更新 | 关注最新动态 |

## 八、平台选择建议

| 场景 | 推荐平台 | 原因 |
|------|----------|------|
| 毕业论文（本科） | 知网 | 大多数高校使用知网 |
| 毕业论文（研究生） | 知网 | 几乎所有高校使用知网 |
| 期刊投稿 | 知网/维普 | 根据目标期刊要求 |
| 课程论文 | PaperPass/维普 | 操作便捷 |
| AI检测自查 | 格子达 | AI检测较严格 |
| 全面检测 | 多平台交叉 | 不同平台各有侧重 |

**建议**：如果不确定目标平台，建议以知网标准进行改写（最严格），这样可以兼容大多数平台。
