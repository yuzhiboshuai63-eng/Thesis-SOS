# AI生成文本的典型模式特征库

本文档整理了AI生成文本的典型特征模式，用于识别和消除AI痕迹，帮助降低AI检测率。

---

## 一、句式层面特征

### 1.1 句子长度分布

| 特征 | AI文本表现 | 人类文本表现 |
|------|-----------|-------------|
| 平均句长 | 25-35字，分布集中 | 15-40字，分布分散 |
| 句长标准差 | 较小（5-8字） | 较大（10-15字） |
| 长短句交替 | 缺乏，句子长度趋于均匀 | 自然交替，有明显节奏感 |

**消除策略**：
- 刻意制造8-15字的短句
- 保留部分30-45字的长句
- 确保句长标准差 > 10字

### 1.2 句式结构

| 特征 | AI文本表现 | 消除方法 |
|------|-----------|----------|
| 主谓宾结构占比 | 过高（>70%） | 增加倒装句、被动句、省略句 |
| 复合句使用 | 过于规整的并列复合句 | 使用更自然的从句嵌套 |
| 修辞句 | 几乎不使用 | 适当加入设问、反问、排比 |

### 1.3 句首模式

AI文本常见的句首模式（高频出现即为AI特征）：

| 高频句首 | 出现频率(AI) | 出现频率(人类) | 替代方案 |
|----------|-------------|---------------|----------|
| "随着...的发展" | 极高 | 中等 | "近年来"、"在...背景下"、"...的快速演进" |
| "本文/本研究" | 极高 | 中等 | "笔者"、"该工作"、"此项研究"、"我们的工作" |
| "首先...其次...最后" | 高 | 低 | "一方面...另一方面..."、"其一...其二..."、自然过渡 |
| "综上所述" | 高 | 中等 | "归纳来看"、"总的来讲"、"概而言之" |
| "值得注意的是" | 高 | 低 | "需要指出的是"、"不可忽视的是"、"应当看到" |
| "因此" | 高 | 中等 | "基于此"、"由此可见"、"故而" |
| "此外" | 高 | 中等 | "与此同时"、"不仅如此"、"加之" |
| "然而" | 中等 | 中等 | "不过"、"尽管如此"、"但" |

## 二、段落层面特征

### 2.1 段落结构

| 特征 | AI文本表现 | 人类文本表现 |
|------|-----------|-------------|
| 段落模式 | 高度一致的"总-分-总" | 多样化：归纳式、演绎式、对比式等 |
| 段首句 | 几乎都是主题句 | 有时以引用、数据、案例开头 |
| 段尾句 | 几乎都是总结句 | 有时开放性结尾，留有思考空间 |
| 段落长度 | 非常均匀（200-300字） | 长短不一（100-500字） |
| 论述方式 | 正反面高度对称 | 适当突出重点，不必面面俱到 |

### 2.2 段落间衔接

| 特征 | AI文本表现 | 人类文本表现 |
|------|-----------|-------------|
| 过渡方式 | 机械使用连接词 | 语义自然衔接，有时无需过渡词 |
| 逻辑关系 | 过于清晰和线性 | 偶尔有跳跃性思维 |
| 重复率 | 段首经常重复上文关键词 | 更自然的指代和省略 |

## 三、词汇层面特征

### 3.1 高频AI词汇

以下词汇在AI文本中出现频率显著高于人类文本：

| 词汇/短语 | AI频率 | 说明 |
|-----------|--------|------|
| "深入" | 极高 | AI喜欢用"深入分析"、"深入研究" |
| "全面" | 极高 | "全面分析"、"全面了解" |
| "有效" | 高 | "有效解决"、"有效提高" |
| "充分利用" | 高 | AI的标准搭配 |
| "具有重要意义" | 高 | AI的万能评价 |
| "发挥着重要作用" | 高 | AI的万能评价 |
| "不可或缺" | 高 | AI的万能评价 |
| "日益" | 高 | "日益增长"、"日益严重" |
| "不断" | 高 | "不断发展"、"不断提高" |
| "显著" | 高 | "显著提高"、"显著改善" |

### 3.2 词汇多样性

| 指标 | AI文本 | 人类文本 |
|------|--------|----------|
| TTR（类型-词元比） | 较低（0.4-0.5） | 较高（0.5-0.7） |
| 重复用词 | 同一表达反复出现 | 同一概念用不同方式表达 |
| 词汇丰富度 | 中等但均匀 | 高且不均匀 |

### 3.3 搭配模式

AI文本的典型搭配模式：

| AI典型搭配 | 替代方案 |
|-----------|----------|
| "进行了深入的分析" | "从多个维度进行了剖析" / "细致地解读了..." |
| "取得了显著的效果" | "成效颇为可观" / "实际表现令人满意" |
| "具有重要的理论意义和实践价值" | "在学术层面和实际应用中均有其独到之处" |
| "为...提供了有力的支撑" | "从...角度给予了切实的保障" |
| "在...方面发挥着越来越重要的作用" | "...的价值正日益受到学界和业界的关注" |

## 四、语义层面特征

### 4.1 困惑度（Perplexity）

| 特征 | AI文本 | 人类文本 |
|------|--------|----------|
| 困惑度 | 较低（文本可预测性强） | 较高（表达更多样） |
| 下一词预测 | 容易预测 | 较难预测 |
| 表达方式 | "最标准"的表达 | 偶尔使用非标准但准确的表达 |

**提高困惑度的方法**：
- 使用稍微出人意料但准确的措辞
- 避免选择"最常见"的同义词
- 偶尔使用倒装或非常规语序
- 加入一些个人化的表达习惯

### 4.2 语义连贯性

| 特征 | AI文本 | 人类文本 |
|------|--------|----------|
| 逻辑链 | 过于完美和线性 | 偶尔有跳跃或回溯 |
| 信息密度 | 均匀分布 | 有疏密变化 |
| 论述深度 | 各部分深度一致 | 重点部分更深入 |

### 4.3 情感与立场

| 特征 | AI文本 | 人类文本 |
|------|--------|----------|
| 情感表达 | 中立、平衡 | 有时有微妙的倾向性 |
| 立场表达 | 避免明确立场 | 有时表达明确的个人判断 |
| 评价方式 | 正反两面都提到 | 有时只强调重点 |

## 五、消除AI特征的具体技巧

### 5.1 句子层面

```
技巧1：制造句长波动
  原文（AI风格）："本研究采用深度学习方法对文本进行分类，并取得了较好的实验结果。"
  改写（人类风格）："在文本分类任务上，我们引入了深度学习技术。效果令人满意。"

技巧2：使用口语化学术表达
  原文（AI风格）："该方法的性能显著优于现有方法。"
  改写（人类风格）："说实话，这个方案的表现确实比目前主流的方法要好不少。"
  （注意：需根据论文类型适当使用，正式论文中不宜过多）

技巧3：加入个人判断
  原文（AI风格）："实验结果表明该方法有效。"
  改写（人类风格）："从实验数据来看，笔者倾向于认为该方案是切实可行的。"

技巧4：使用设问句
  原文（AI风格）："该方法具有计算效率高的优点。"
  改写（人类风格）："为什么选择这种方法？一个关键原因在于其计算效率方面的突出表现。"
```

### 5.2 段落层面

```
技巧1：打破"总-分-总"模式
  原文（AI风格）：主题句 → 论据1 → 论据2 → 论据3 → 总结句
  改写（人类风格）：案例引入 → 分析 → 主题句 → 补充论据 → 开放性结尾

技巧2：改变段落长度
  将均匀的200-300字段落改为长短交替（100字、400字、150字、350字...）

技巧3：使用非常规的段落开头
  以数据开头："85.3%的受访者表示..."
  以引用开头："正如张三（2020）所指出的..."
  以案例开头："以某市为例..."
  以问题开头："如何解决这个问题？"
```

### 5.3 词汇层面

```
技巧1：替换AI高频词
  "深入" → "细致"、"系统"、"从多角度"
  "全面" → "系统性地"、"多维度地"
  "有效" → "切实"、"可行"、"管用"
  "显著" → "明显"、"可观"、"突出"

技巧2：增加词汇多样性
  对同一概念，在不同位置使用不同的表达方式
  例如："提高" → "增强" → "改善" → "提升" → "促进"

技巧3：使用领域内惯用表达
  加入一些只有从业者才会使用的简称和惯用语
```

## 六、AI检测平台特征差异

| 平台 | 检测侧重 | 敏感特征 | 建议优先消除 |
|------|----------|----------|-------------|
| 知网AIGC | 综合检测 | 句式均匀性、词汇重复 | 句式多样性和词汇多样性 |
| 格子达 | 严格AI检测 | 困惑度、突发性 | 制造句长波动和表达变化 |
| PaperYY | 综合检测 | 段落结构模式化 | 打破固定段落模式 |
| 万方 | 偏重重复率 | 连续字符匹配 | 语义深度改写 |
| 维普 | 关键词+结构 | 句式结构重复 | 句式变换 |
